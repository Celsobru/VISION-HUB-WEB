Gerar Backup

Faça download de uma cópia completa do banco de dados, incluindo todos os clientes, planos, pagamentos, tickets e configurações.

🔄

Restaurar Backup

Restaure um backup anterior. Um backup de segurança do banco atual será criado automaticamente antes da restauração.

ℹ️ Informações importantes:
• O backup contém todos os dados: clientes, logins, senhas (criptografadas com bcrypt), planos, pagamentos e tickets.
• Ao restaurar, o banco atual é substituído pelo arquivo enviado.
• Um backup de segurança é criado automaticamente na pasta server/backups/ antes de cada restauração.
• O arquivo de backup tem formato .db (SQLite).
• Recomendamos fazer backup regularmente como precaução.
